
# 🚀 MedClin - Site Institucional

Site institucional desenvolvido para a MedClin, empresa especializada em Medicina Ocupacional e Segurança do Trabalho, oferecendo soluções para empresas e seus colaboradores.

## 📋 Sobre o Projeto

O projeto consiste no desenvolvimento de um site institucional para a MedClin, com o objetivo de apresentar a empresa, divulgar seus serviços e facilitar o contato com clientes e empresas interessadas.

A plataforma possui uma interface moderna e organizada, apresentando informações sobre a empresa, seus serviços, diferenciais e canais de atendimento.

## ⚙️ Funcionalidades

- [ ] Página inicial com apresentação da empresa.
- [ ] Seção institucional com informações sobre a MedClin.
- [ ] Apresentação dos serviços oferecidos.
- [ ] Seção de vantagens e diferenciais.
- [ ] Área de contato com integração ao WhatsApp para atendimento.
- [ ] Informações de endereço.
- [ ] Navegação entre as seções do site.

## 🛠️ Tecnologias Utilizadas

As principais tecnologias utilizadas no desenvolvimento foram:

- **Linguagem:** JavaScript
- **Frontend:** HTML e CSS
- **Ferramentas:** VS Code, Git e GitHub

## 📌 Soluções Apresentadas

O site apresenta diferentes soluções na área de Medicina Ocupacional e Segurança do Trabalho:

- **Exames Ocupacionais:** dmissionais, demissionais, periódicos, mudança de função e retorno ao trabalho.
- **PCMSO::** Programa de Controle Médico de Saúde Ocupacional.
- **PGR:** Programa de Gerenciamento de Riscos.
- **LTCAT:** Laudo Técnico das Condições Ambientais do Trabalho.
- **Exames Complementares:** audiometria, raio-X, ECG, acuidade visual e outros.
- **PPP:** Perfil Profissiográfico Previdenciário.
- **eSocial SST:** envio dos eventos S-2210, S-2220 e S-2240.
- **Assessoria e Laudos:** suporte especializado em Saúde e Segurança do Trabalho.
